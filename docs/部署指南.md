# 部署指南

> 目标：让评审可以通过公网地址访问「拾光旅行」，并可使用 AI 行程规划、AI 旅行管家和后台 AI 初审。

## 一、Docker Compose 部署（推荐）

### 1. 服务器要求

- 2 核 4 GB 以上 Linux 服务器（Ubuntu 22.04 / Debian 12 推荐）
- 已安装 Docker 24+ 与 Docker Compose v2
- 已备案域名（国内服务器）与安全组放行 80/443

### 2. 上传项目

```bash
# 在服务器上
git clone <你的仓库地址> shiguang-travel
cd shiguang-travel
cp .env.example .env
```

编辑 `.env`：

```env
MYSQL_ROOT_PASSWORD=换成强密码
JWT_SECRET=用 openssl rand -base64 48 生成
AI_API_KEY=sk-你的DeepSeek密钥
WEB_PORT=8088
BACKEND_PORT=8080
CORS_ALLOWED_ORIGINS=http://你的域名
```

> `.env` 已在 `.gitignore` 中，绝对不要提交到公开仓库。

### 3. 启动

```bash
docker compose up -d --build
docker compose ps
docker compose logs -f backend
```

首次启动会自动：

1. 创建 MySQL 容器并导入 `database/lvyou_full.sql`；
2. 启动 Redis；
3. 构建并启动 Spring Boot 后端；
4. 构建 Vue 前端并由 Nginx 托管；
5. `DatabaseInitializer` 补齐表结构并确保演示账号存在。

访问 `http://服务器IP:8088`。

### 4. 绑定域名与 HTTPS

把域名 A 记录解析到服务器 IP，然后：

```bash
sudo apt install -y nginx certbot python3-certbot-nginx
```

将 `deploy/nginx.conf` 中的 `server_name` 改成你的域名，把 80 代理到
`127.0.0.1:8088`，再执行：

```bash
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d your-domain.example.com
```

或者直接在云厂商控制台配置 HTTPS 证书并回源到 8088。

### 5. 验证

```bash
curl http://127.0.0.1:8088/api/ai/health
```

在本地 Windows 电脑上可执行完整冒烟测试：

```powershell
powershell -File scripts/smoke-test.ps1 -BaseUrl http://你的域名
```

浏览器访问：

- 前台：`http://你的域名/`
- AI 行程：`http://你的域名/ai/planner`
- 后台：`http://你的域名/admin`（手机号 `13800138000`，密码 `123456`）

## 二、手动部署（不使用 Docker）

### 1. 准备环境

- JDK 17+
- Maven 3.8+
- Node.js 18+
- MySQL 8.x
- Redis 7（可选，未启动时 AI 缓存/限流会自动降级为单机内存）
- Nginx 1.20+

### 2. 初始化数据库

```bash
mysql -u root -p --default-character-set=utf8mb4 < database/lvyou_full.sql
```

### 3. 构建后端

```bash
cd travel-backend
cp .env.example .env
# 编辑 .env：DB_PASSWORD、JWT_SECRET、AI_API_KEY
./mvnw clean package -DskipTests
nohup java -jar target/travel-backend-1.0.0.jar > backend.log 2>&1 &
```

### 4. 构建前端

```bash
cd travel-frontend
npm ci
npm run build
sudo mkdir -p /var/www/shiguang-travel
sudo cp -r dist /var/www/shiguang-travel/
```

### 5. 配置 Nginx

```bash
sudo cp deploy/nginx.conf /etc/nginx/sites-available/shiguang-travel
sudo ln -s /etc/nginx/sites-available/shiguang-travel /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

> `scenic_photos/` 需要放在后端工作目录的上一级（`travel-backend/../scenic_photos`）。
> 如果后端从其他目录启动，请把图片目录放到对应位置，或修改
> `ScenicSpotController` 中的路径配置。
